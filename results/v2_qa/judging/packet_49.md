## q481

**A**
- shows: information, details, help, about, notification, status, alert, data, reference, documentation
- means: seeking information; reviewing details; checking status; referencing documentation; investigating an issue; clarifying requirements
- note: The icon is a universal symbol for information or help. It is useful for tasks that involve research, reading documentation, or clarifying details, but it is too generic for action-oriented tasks like creating or fixing things.

**B**
- shows: outlined fan-shaped Wi-Fi signal wedge; modifiers: lowercase letter 'i' (information symbol) inside the wedge
- means: Wi-Fi or wireless network information / details; Wi-Fi captive portal or login prompt; wireless network status or diagnostics
- note: The icon depicts a Wi-Fi signal sector containing a lowercase 'i', representing wireless network information, credentials, or a captive portal status. It fits tasks about documenting, checking, or sharing Wi-Fi details (SSIDs, passwords, IP settings), though at small sizes the 'i' is very easily mistaken for an exclamation mark ('!') indicating a Wi-Fi warning or error.
